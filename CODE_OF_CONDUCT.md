# Code of Conduct

This Code of Conduct is intentionally short and focuses on the basic expectations for respectful and constructive participation in the Sendra community.

## The standard

Be respectful. Disagree with ideas, not people. Assume good faith, and
give others the benefit of the doubt before assuming bad intent.

Harassment, personal attacks, discriminatory language or behavior, and
deliberately disruptive conduct are not welcome here, in issues, pull
requests, discussions, or any other project space.

## Enforcement

If someone's behavior in a project space falls short of this, open an
issue or contact the maintainer directly. Reports will be handled
privately and proportionately — a first-time misstep gets a
conversation, not a ban; a pattern of it does not.

## Scope

This applies to all Sendra project spaces: the repository, its issues
and pull requests, and any official discussion channels.
